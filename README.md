# Backrooms: Cadê a Porta? (site de download)

Site estático publicado com GitHub Pages. Mostra a versão mais recente lida das **Releases** deste repositório.

## Lançar uma versão
1. Em **Releases → Draft a new release**, crie uma tag (ex.: `v0.1.0`).
2. Escreva as notas (elas aparecem no site) e anexe o `.zip` do jogo.
3. Publique. O site mostra versão, data, tamanho e o botão de download automaticamente.

## Imagens
As imagens ficam na pasta `assets/` (`banner.png`, `capa.png`, `icone.ico`).
